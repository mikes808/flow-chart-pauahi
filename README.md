# Flowchart Template with Durations

An editable flowchart template: click any text to edit, set a duration on each step, and see total time and start times update. Export the flowchart as a fillable PDF.

## Host on GitHub Pages
1. Put `index.html` in the root of a repository.
2. In the repo, go to **Settings → Pages**, set **Source** to "Deploy from a branch", pick `main` and `/ (root)`, and save.
3. The site appears at `https://<your-username>.github.io/<repo-name>/` after a minute or two.

Edits are saved in your browser's local storage, per device.
